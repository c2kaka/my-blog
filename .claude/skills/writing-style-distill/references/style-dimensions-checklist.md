# Style dimensions checklist（可选深入）

成文前可按下列清单扫一遍语料，防止漏维度。

## 句法层

- [ ] 平均句长（可抽样 20 句估算）
- [ ] 复合句 vs 流水句偏好
- [ ] 重复修辞（排比、首尾呼应）

## 词汇层

- [ ] 口头禅或衔接词（「说实话」「换句话说」「关键在于」）
- [ ] 抽象 vs 具象名词比例
- [ ] 脏话/梗/网络用语频度与语境

## 篇章层

- [ ] 开篇三种常见钩子（统计哪种最多）
- [ ] 结尾：升华 / 留白 / 召唤行动 / 自嘲
- [ ] 小标题风格（问句式 / 名词短语 / 数字）

## 人际与伦理

- [ ] 对读者的预设（同行 / 小白 / 批判对象）
- [ ] 自称与他称（我们/你/有人）

## 英文化与标点

- [ ] 中英文混排空格习惯
- [ ] 破折号与省略号情感负荷

记录结论到主 SKILL 的「写作规则」与 `style-anchors.md`。
