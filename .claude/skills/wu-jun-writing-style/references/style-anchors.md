# Style anchors · short evidence snippets

规则对应的**简短锚点**（摘自书中可读段落，用于校对风格；不宜当作可引用“原句”做事实主张——正式引用请对照纸质书或授权电子版）。

| Rule (summary) | Anchor |
|----------------|--------|
| 先回应读者可能的反驳 | 「看到这个标题，你可能会想，这不是宣扬宿命论或者出身论吗？其实恰恰相反……」 |
| 「命/运」框架讲清随机性与结构 | 「运气是一时的……但命却影响人的一生，起着决定作用。」 |
| 故事 + 抽象收束 | 邻家师姐清华超常发挥，收束为「一辈子的命」与见识的关系。 |
| 古典 + 西方并排 | 「孔子曰：『从心所欲，不逾矩。』……古希腊……宙斯……命运女神」 |
| 场景化思想实验 | 「如果有人在大街上扇了我们一个耳光，我们会做何反应呢？」→ 三种态度对应命运。 |
| 撒切尔引文支撑链条 | 想法→言辞→行动→习惯→性格→命运。 |
| 历史案例作“方法论”反例 | 李广「看问题和做事的方法有很大的问题」 versus 战功与封侯。 |
| 收束到现实提问 | 「讲完历史，回到我们的现实。」 |
| 概念操作化 | 「从 3 分做到 10 分靠的就是常识」；常识 vs 科学 vs 艺术分工。 |
| 自我经验降维举例 | 女儿选课、与父母沟通方式、风投朋友「独一无二的价值」。 |
| 口语分寸感 | 「不作不死」「浑不吝」等少量俗语点题，不堆叠。 |

## Occasional / context-bound（偶发或依赖语境）

- 具体公司名、行业例子（书中有时代性）：写法上是「个案印证观点」，换新题材时应替换为同等功能的例子，不要硬套原名。
